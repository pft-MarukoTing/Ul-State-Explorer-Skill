# Design System Map examples

Examples of the team-owned map described in `ui-state-explorer/references/design-system-map.md`.

These files are **not** part of the installed skill (only `ui-state-explorer/` is copied), so the skill never applies one team's choices to another team's UI. To use a map, copy it to where the skill looks for it — a web project's root as `design-system-map.md`, a `Design System Map` frame in your Figma file, or pass its path in the request.
